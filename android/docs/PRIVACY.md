# 隐私说明

过敏原雷达 Android beta 没有账号、广告 SDK、Firebase、分析跟踪或健康档案功能。

## 位置

- 应用只声明前台 `ACCESS_COARSE_LOCATION`，且仅在用户点按“使用当前位置”后请求系统权限。
- 不请求精确位置或后台位置；没有定位 Worker、持续监听、地理围栏或 GPS 轮询。
- 坐标仅在设备内存中传给本地的附近支持位置匹配器，匹配完成后立即丢弃；不会上传给 API、写入日志、Room、DataStore、通知或测试产物。
- 用户必须确认候选位置后，DataStore 才会保存标准的 `selectedLocationId`。手动选择位置始终可用。

## 本地数据与备份

- Room 保存最近成功的花粉 API 响应，供离线显示；它不是位置轨迹，且被明确排除在云备份和设备迁移之外。
- 备份规则只包含 `location_preferences`（已确认的标准位置编号）和 `risk_alert_preferences`（提醒开关、对象、阈值及去重指纹）。
- 位置列表来自网络或 Room 缓存；缓存来源会在界面中标识。

## 通知与数据来源

- 风险提醒默认关闭。开启后，设备仅以已选择位置的真实网络数据进行本地评估；缓存、估算、未知风险和空蒿属结果不会触发提醒。
- 综合花粉主要来自 WeatherDT。北京蒿属仅在上游提供有效的独立结果时显示，不由综合花粉推算。
- 花粉信息仅供健康防护参考，不构成医疗建议、诊断或官方预报。
